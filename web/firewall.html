Guards, always: never block SSH, never touch Docker's own rules, remove only rules Helm created. Rules are saved after every change, so they survive a reboot — reboot survival is not yet verified live, test after push. Docker apps are blocked on their container port, not their host port — the box itself does not block Docker ports, so a block on the wrong port matches nothing. You never need to type a firewall command, and you never need to know rule order — Helm handles that.
